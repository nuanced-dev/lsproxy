
# Contributing

Nuanced LSP is maintained but not under active development. We do accept bug fixes, documentation improvements, and small, well-scoped extensions. Supporting larger extensions or feature requests are out of scope.

## Development

Check out the development documentation for the [service](DEVELOPMENT.md) and [TypeScript client](clients/typescript/DEVELOPMENT.md) to get started on your contribution.

## Submitting a pull request

All contributions must be submitted in the form of a pull request:

1. Fork and clone the repository
1. Make sure the tests pass on your machine
1. Make sure linter passes on your machine
1. Make your change, add tests, and make sure the tests and linter still pass
1. Push to your fork and submit a pull request

Pay attention to the following to help us review and accept your pull request:

- Follow style and conventions from the existing code.
- Write tests for new features and changed behaviors.
- Keep the changes focused. For larger changes consider breaking them up in smaller pull requests to make reviewing them easier.
- Write a [good commit message](http://tbaggery.com/2008/04/19/a-note-about-git-commit-messages.html).
