# Support

Nuanced LSP is maintained but not under active development. Supporting larger extensions, feature requests, or support with custom integration and deployment scenarios are out of scope.

## How to file issues and get help

This project uses GitHub issues to track bugs and feature requests. Please search the existing issues before filing new issues to avoid duplicates. For new issues, file your bug as a new issue. Make sure to include all necessary details to replicate the issue or we won't be able to support you.

For help or questions about using this project, please start a [discussion](https://github.com/nuanced-dev/lsp/discussions).
